# Releases

## v1.0.1

Published on [GitHub](https://github.com/lioristhmus/local-analytic-einstein-metrics/releases/tag/v1.0.1)
and [Zenodo](https://doi.org/10.5281/zenodo.24318760), DOI
`10.5281/zenodo.24318760`.

This version adds a SageMath/Python computational-check statement and a link
to the supplement in the AI-use disclosure. Mathematical content is unchanged
from [v1.0](https://github.com/lioristhmus/local-analytic-einstein-metrics/releases/tag/v1.0).

The release provides:

- `local-analytic-einstein-metrics-en-v1.0.1.pdf` — paper.
- `local-analytic-einstein-metrics-source-v1.0.1.zip` — Markdown, TeX, bibliography and Kasner companion.
- `local-analytic-einstein-metrics-computations-v1.0.1.zip` — code, inputs, environments, results and paper-to-code map.
- `local-analytic-einstein-metrics-v1.0.1.zip` — complete repository snapshot.
- `SHA256SUMS` — SHA-256 checksums for the four files above.

After downloading the files into one directory, verify them with:

```sh
shasum -a 256 -c SHA256SUMS
```

The Kasner companion, `exact-set-checks-v0.1.1.zip`, is at
`paper/exact-set-checks-v0.1.1.zip` in the repository and all three ZIPs.
The [verification guide](VERIFICATION.md) describes the file checks and
mathematical coverage. [LICENSES.md](../LICENSES.md) gives the license scopes.
