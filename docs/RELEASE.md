# Prepared v1.0 release

Title: *Local analytic Einstein metrics from free curvature data in four dimensions*. Author: Lior Isthmus.

The publication files are derived from editorial v0.1.12, with mathematical
content unchanged. The companion finite-check archive retains version
v0.1.1 and its original bytes. This is a separate paper from the previously
published projective twistor correspondence.

Planned release assets:

- `local-analytic-einstein-metrics-en-v1.0.pdf`
- `local-analytic-einstein-metrics-source-v1.0.zip`
- `local-analytic-einstein-metrics-computations-v1.0.zip`
- `local-analytic-einstein-metrics-v1.0.zip` (the curated repository snapshot)
- `SHA256SUMS`

GitHub publication comes first, then a new Zenodo preprint record using
the same files. ORCID can then identify this work using its Zenodo DOI.
DOI and public URLs are added only after they exist. No Hexagon submission
is planned. All services are currently unmodified by this preparation.

The expanded local preparation includes the unchanged precursor r3 supplement
and its current-paper coverage map. It supersedes the smaller local preparation
for publication; the paper PDF and mathematical content remain unchanged.
