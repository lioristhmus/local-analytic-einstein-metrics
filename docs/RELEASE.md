# Prepared v1.0.1 release

Title: *Local analytic Einstein metrics from free curvature data in four dimensions*. Author: Lior Isthmus.

The publication files derive from editorial v0.1.12 with copyediting,
bibliographic and layout corrections from prepublication review. Mathematical
content, assumptions, notation and theorem numbers are unchanged. The companion finite-check archive retains version
v0.1.1 and its original bytes. This is a separate paper from the previously
published projective twistor correspondence.

Planned release assets:

- `local-analytic-einstein-metrics-en-v1.0.1.pdf`
- `local-analytic-einstein-metrics-source-v1.0.1.zip`
- `local-analytic-einstein-metrics-computations-v1.0.1.zip`
- `local-analytic-einstein-metrics-v1.0.1.zip` (the curated repository snapshot)
- `SHA256SUMS`

GitHub publication comes first, then a new Zenodo preprint record using
the same files. ORCID can then identify this work using its Zenodo DOI.
DOI and public URLs are added only after they exist. No Hexagon submission
is planned. At the preparation of this snapshot (2026-11-18), none of these
services had been modified by this preparation.

The expanded local preparation includes the unchanged precursor r3 supplement
and its current-paper coverage map. It supersedes the smaller local preparation
for publication. The mathematical code, inputs and saved results remain
unchanged. The companion `exact-set-checks-v0.1.1.zip` is at
`paper/exact-set-checks-v0.1.1.zip` inside the source and computation ZIPs,
as well as the full repository snapshot. Its README retains its original
working title and version.

Version 1.0.1 adds the computational-check disclosure and a link to the
computational supplement. Mathematical content is unchanged from v1.0.
The published v1.0 tag and release assets are retained.
