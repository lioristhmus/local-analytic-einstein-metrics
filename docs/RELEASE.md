# Releases

## v1.0.2

This version updates the paper's companion link, citation metadata and
license notices, and simplifies the supplement's documentation. Mathematical
content, computational code, inputs and recorded results are unchanged.

The distribution contains:

- `local-analytic-einstein-metrics-en-v1.0.2.pdf` — paper.
- `local-analytic-einstein-metrics-source-v1.0.2.zip` — Markdown, TeX, bibliography and companion archive.
- `local-analytic-einstein-metrics-computations-v1.0.2.zip` — code, inputs, environments, results and paper-to-code map.
- `local-analytic-einstein-metrics-v1.0.2.zip` — complete repository snapshot.
- `SHA256SUMS` — SHA-256 checksums for the four files above.

After downloading the files into one directory, verify them with:

```sh
shasum -a 256 -c SHA256SUMS
```

The companion, `exact-set-checks-v1.0.2.zip`, is at `paper/exact-set-checks-v1.0.2.zip` in the repository
and all three ZIPs. It includes license notices and the exact Kasner code,
inputs and saved results.

The [verification guide](VERIFICATION.md) describes the file checks and
mathematical coverage. [LICENSES.md](../LICENSES.md) gives the license scopes.
